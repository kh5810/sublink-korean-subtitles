# SubLink — 유튜브 한글 자막 프로토타입

## 실행 방법 (Windows 10/11)

1. Python 3.10 이상을 설치합니다. 설치 화면에서 **Add Python to PATH**를 체크하세요.
2. 이 폴더에서 주소창에 `cmd`를 입력해 명령 프롬프트를 엽니다.
3. 아래 명령을 차례대로 실행합니다.

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py app.py
```

4. 브라우저에서 `http://127.0.0.1:5000` 을 엽니다.
5. 유튜브 링크를 입력하고 `영상 열기 + 자막 가져오기`를 누릅니다.
6. 자막을 가져오면 `한국어로 번역하기`를 누릅니다. 자막을 못 가져오는 영상은 `.srt` 또는 `.vtt` 파일을 직접 올릴 수 있습니다.

## 번역 서비스와 무료 이용

기본 번역 주소는 `https://libretranslate.com/translate`입니다. 공개 번역 서비스는 사용량 제한, API 키 요구, 일시적 장애가 있을 수 있습니다. 이 경우 무료로 자체 번역 서버를 실행할 수 있습니다.

자체 번역 서버를 설치한 뒤, 같은 명령 프롬프트에서 서버 주소를 지정하세요.

```bat
set TRANSLATE_URL=http://127.0.0.1:5001/translate
py app.py
```

LibreTranslate 자체 서버 설치 예시는 공식 문서를 확인하세요: https://docs.libretranslate.com/

API 키가 필요한 번역 서비스를 쓰는 경우:

```bat
set TRANSLATE_API_KEY=여기에_발급받은_키
py app.py
```

## 중요한 제한

- 이 앱은 유튜브 공식 임베드 플레이어로 영상을 재생합니다. 영상 파일을 다운로드하거나 유튜브 영상에 영구 자막을 삽입하지 않습니다.
- 유튜브의 모든 영상에서 자막을 가져올 수 있는 것은 아닙니다. 자막이 없거나 비공개/연령 제한/지역 제한/접근 제한이 있으면 실패할 수 있습니다.
- YouTube Data API의 자막 다운로드 기능은 OAuth 권한이 필요할 수 있습니다. 이 프로토타입은 `yt-dlp`를 이용해 사용 가능한 자막을 시도하고, 실패 시 자막 파일 업로드를 제공합니다.
- 번역은 기계 번역이므로 문맥이나 고유명사를 잘못 번역할 수 있습니다.
- 기본 구성은 개인 PC에서 로컬로 실행하는 용도입니다. 공개 웹사이트로 배포하려면 보안, 요청 제한, 외부 서비스 이용약관, 서버 비용 등을 별도로 검토해야 합니다.
- 유튜브 임베드가 금지된 영상은 플레이어에서 재생되지 않을 수 있습니다.

## 파일

- `app.py`: Flask 백엔드, 자막 가져오기/파싱/번역
- `templates/index.html`: 웹 화면과 자막 동기화
- `requirements.txt`: 필요한 Python 패키지


## 문제 해결

### 브라우저에 `Failed to fetch`가 표시될 때
- 웹사이트를 연 검은 명령 프롬프트 창이 닫히지 않았는지 확인합니다.
- 서버가 종료됐다면 폴더에서 ` .venv\Scripts\activate ` 후 `py app.py`를 실행하고 `http://127.0.0.1:5000`으로 접속합니다.
- `file:///.../index.html`로 열지 말고 반드시 `http://127.0.0.1:5000`으로 엽니다.

### 유튜브 플레이어 오류 153
- 반드시 `http://127.0.0.1:5000` 또는 `http://localhost:5000`에서 엽니다.
- 브라우저 광고 차단/추적 차단 확장 기능이 유튜브 플레이어 요청을 막는지 확인합니다.
- 영상 소유자가 외부 사이트 재생을 차단한 영상은 이 사이트에서 재생할 수 없습니다. 이 경우 유튜브에서 직접 영상을 열어야 합니다.



## 오류가 계속될 때

- 사이트는 반드시 `http://127.0.0.1:5000` 주소로 열어 주세요. `index.html` 파일을 직접 더블클릭해 열면 API 요청이 작동하지 않습니다.
- 검은 명령 프롬프트 창을 닫으면 서버가 종료됩니다. 창을 켜 둔 상태에서 사이트를 이용하세요.
- 유튜브 오류 153은 유튜브가 임베드 요청의 출처(Referer)를 받지 못할 때 발생할 수 있습니다. 최신 버전은 참조 정책을 명시하지만, 브라우저 확장 기능이나 유튜브의 제한으로 일부 영상은 여전히 재생되지 않을 수 있습니다.
- 번역은 외부 무료 번역 서비스에 의존합니다. 해당 서비스가 요청을 거부하거나 제한하면 사이트의 자막 번역도 실패할 수 있습니다.
- 영상 소유자가 외부 재생을 막았거나 영상이 연령 제한/비공개라면 사이트 안에서 재생할 수 없습니다.
